## The offer

**In one sentence:** "A website that books, quotes and keeps your clients updated, on one monthly plan."

**Who it's for:** owner-run service businesses in Bergen County with roughly 2–25 staff. Home services and care agencies first, because we have proof there (Jones Pressure Washing, 360 Degree Care).

### Plans

Prices are built from our current QuickBooks rates, raised about 15% (see Pricing).

| Plan | What's included | Setup | Monthly |
| --- | --- | --- | --- |
| Tools-only | Tools added to their existing site, lead alerts, monthly report, tool support | $350 per integrated tool, $750 per built tool | $99 per tool |
| Launch | Custom site (about 5 pages), hosting and upkeep, 1 hour of edits, lead alerts, monthly report | From $2,500 | $179 |
| Grow | Launch + one built-in tool + 2 hours of edits | From $3,250 | $349 |
| Operate | Grow + client portal or owner dashboard, up to 3 tools, 3 hours of edits, quarterly strategy call | $1,000 paid discovery, then from $6,000 | From $649 |

Website plans have a 12-month minimum, then run month to month.

### Every website plan includes

- Custom design and build (no templates)
- Hosting, domain and SSL management, backups, security updates, uptime monitoring
- Basic SEO setup: titles and descriptions, schema, site speed, mobile, sitemap, Google Business Profile basics
- A set number of edit hours each month (no rollover)
- Lead alerts by email or text, and a one-page monthly report
- Email support with a stated response time

### Tools-only plan (second front door)

For businesses happy with their current site (WordPress, Wix, Squarespace or custom). We add tools to it without a rebuild.

- An easier yes than a full website; once they're in, the rebuild becomes the upsell
- The setup fee counts toward a Launch or Grow plan if they upgrade within 12 months
- We support the tool, not the rest of their site

### Add-ons

Headshots and team photos, ongoing SEO (local content, city pages, ranking reports), ad management, extra pages, extra tools.

## How the tools work

The tools are one app we host, not code inside each client's site. Each client gets their own settings (prices, services, colors, logo), so a pressure washer's quote calculator and a landscaper's are the same code.

### Levels for integrated tools

How deep we go depends on what the client needs and which plan they're on with the provider. What each provider allows on each plan changes, so check before quoting.

| Level | What we deliver | Typically needs |
| --- | --- | --- |
| Embed | Their booking page on the site, styled to match | Any plan, including free |
| Connected | Bookings flow into our lead alerts, reports and reminders | API or webhook access, usually a paid plan |
| Custom | Our own booking screens and flows on their API (deposits, intake questions, routing) | Paid plan with full API access |

### Getting tools onto any site

| Method | Best for | Works on |
| --- | --- | --- |
| Embed code (a small script on the page) | Quote calculator, booking, review requests | Our sites, WordPress (plugin or snippet), Wix (paid Wix plan) |
| Iframe (our page shown inside theirs) | Fallback when a platform blocks scripts | Almost anything; harder to style |
| Login page on a subdomain (portal.clientsite.com) | Client portal, owner dashboard | Any platform; only needs a DNS record |

- **Styling:** tools take each client's colors and fonts from settings; consistent, but never perfectly native on someone else's theme.
- **Search visibility:** search engines may not read what's inside an embed. Fine for forms and calculators; main page content stays in the site itself.
- **Harder to leave:** if a client changes platforms, the tools move with them.

### Platforms

Our own sites and WordPress first. Two current clients are on Wix plans for the next 2–2.5 years; if either wants tools, they become our first Wix sites and we build Wix support then.

### Data

One Postgres database for all tools, with a client ID on every row and access rules so each client sees only their own data. Supabase fits best: it adds logins and file storage (needed for the portal), and we already run it for Domani. A database per tool would split data the monthly report needs together. Sanity is a content system, so it's an option later for client-editable site content, not tool data.

## Delivery and support

Monthly clients judge us on how fast and predictably we respond. Write the process down before the first plan client signs.

### Onboarding (target: live in 4–6 weeks)

1. Kickoff call and intake form: services, prices, photos, logins, the tool they need most
2. Headshot shoot booked, if they want it
3. Design, build, one round of revisions
4. Launch, connect lead alerts, walk the owner through their tools
5. Add the client to the PVS dashboard for tracking and reports

### Ongoing support

- One way to ask for help (an email address or a form), never personal texts
- Response time: within 1 business day; site-down issues the same day
- Clear line between an edit (included) and a new feature (quoted)
- Edit requests tracked in the dashboard, so we see hours per client
- Standard hosting setup with uptime and error monitoring on every site
- A backup plan for when Phil or Sami is out for a week

## Keeping and growing clients

This is where Sami's AT&T idea pays off. Each month the client sees what they get; each quarter we spot the next thing they need.

- **Monthly report (automated):** visitors, leads, calls, bookings or quotes, and what we changed. Sent from the PVS dashboard.
- **Quarterly check-in (15–20 minutes):** what's working, what's annoying them, what's next.

| When we see this | We offer this |
| --- | --- |
| Missed calls or slow replies to leads | Missed-call text-back, appointment reminders |
| Many edit requests | The next plan level |
| Steady leads but messy follow-up | Client portal or owner dashboard |
| Few leads | Ongoing SEO or ads |
| Seasonal or repeat work | Maintenance plan sign-ups |
| New staff or a new location | Headshots, new pages |
| Running the business on spreadsheets | Custom software (the bigger work) |
| Tools-only client happy after 6 months | Full website plan |

**Warning signs:** no logins to their tools, unanswered reports, late payments. Call them before the renewal, not after.

## Risks

The biggest risk is support work growing faster than revenue. Most of the others come from being a two-person team.

| Risk | What it looks like | How we handle it |
| --- | --- | --- |
| Support eats our time | Endless small requests, little time to build | Fixed edit hours tracked per client; move heavy users up a plan |
| Tools built one-off | Each client's tool is different and hard to maintain | Shared tool library; no custom tool inside a plan without a quote |
| Provider limits | A client's free Calendly or Cal.com plan blocks what we promised | Check the client's plan before quoting; sell the matching level |
| Wix limits | Tools look or work worse on Wix | Set expectations up front; offer a rebuild when Wix terms end |
| Clients don't see value | Cancel at renewal | Monthly report, quarterly check-in, act on warning signs |
| Price shoppers from ads | Leads comparing us to $20/month builders | Negative keywords; show plan prices so they filter themselves out |
| Only two of us | Illness or a big project stalls support | Written processes, shared logins, backup coverage |
| Partner problems | Missed shoots or poor ad results under our name | Written agreements, trials first, we stay the client's contact |
| Search rankings drop | Site changes hurt city-page rankings | Keep URLs; change copy only; watch Search Console after each release |
